# Call Emergency — prototipo inicial\n\nIncluye página adaptable, identidad visual de marca y formulario de registro/inicio de sesión listo para conectar con Supabase.\n\n## Próximos pasos\n1. Configurar en Vercel las variables `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_ANON_KEY` con los valores de Project URL y publishable/anon key de Supabase.\n2. Ajustar Site URL y Redirect URLs en Supabase después del despliegue.\n3. Mantener RLS activa. Nunca poner la clave `service_role` en el navegador ni en variables `NEXT_PUBLIC_*`.\n4. Usar datos ficticios hasta revisar permisos y privacidad.\n\nEste proyecto es un prototipo inicial, no una aplicación lista para uso médico o comercial. Todavía faltan panel de perfil, QR funcional y revisión completa de seguridad.
